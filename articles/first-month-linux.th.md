## การกระโดด

หลังจากหลายปีที่พัฒนาใน Windows ผมตัดสินใจเปลี่ยน ไม่มี Dual Boot ไม่มี VM เป็นตัวสำรอง แค่ปุ่มฟอร์แมตกับ USB Stick ที่ลง Ubuntu

## สัปดาห์ที่ 1: กำแพง

![Linux Desktop](iterator_cover.png)

ทุกอย่างยากหมด ผู้จัดการแพ็กเกจ การทำงานใน Terminal ฟังก์ชันคีย์ที่ใช้งานไม่ได้ตั้งแต่แกะกล่อง

ผมเกือบยอมแพ้ในวันที่ 3

## สัปดาห์ที่ 2: รอยร้าวในกำแพง

แล้วบางอย่างก็คลิก ผมเขียน Bash Alias ตัวแรก เข้าใจ `grep` พอที่จะใช้งานจริง ติดตั้ง `tmux` และรู้สึกเหมือนแฮกเกอร์ในหนัง

## สัปดาห์ที่ 3: Flow State

พอถึงสัปดาห์ที่ 3 ผมทำงานได้เร็วกว่าตอนใช้ Windows ด้วยซ้ำ Terminal กลายเป็นส่วนขยายของความคิด `apt install` แทนที่การคลิกผ่าน GUI ถึง 15 นาที

## สิ่งที่อยากให้รู้ก่อน

| ปัญหา | วิธีแก้ |
|---------|----------|
| ขาดไดรเวอร์ | `ubuntu-drivers autoinstall` |
| ฟอนต์ดูไม่ดี | ติดตั้ง `fonts-noto` และเปิด hinting |
| หาแอปไม่เจอ | เรียนรู้ `apt search` และ `flatpak` |
| Terminal น่าเกลียด | ติดตั้ง `kitty` + `zsh` + `powerlevel10k` |

## สรุป

เดือนแรกเจ็บปวด เดือนที่สองเริ่มมีประสิทธิภาพ พอเดือนที่สาม คุณจะสงสัยว่าทำไมรอมานาน

หยุด Dual Boot ซะ กระโดดเลย
