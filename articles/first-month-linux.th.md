## กระโดดเลย

หลังจากพัฒนาบน Windows มาหลายปี ผมตัดสินใจเปลี่ยน ไม่มี Dual Boot ไม่มี VM สำรอง แค่ปุ่มฟอร์แมตกับ USB Stick ที่ลง Ubuntu ไว้

## สัปดาห์ที่ 1: กำแพง

![Linux Desktop](iterator_cover.png)

ทุกอย่างยากไปหมด Package Manager การทำงานบน Terminal ปุ่ม Function ที่ใช้ไม่ได้ตั้งแต่เปิดเครื่อง

ผมเกือบยอมแพ้ตั้งแต่วันที่ 3

## สัปดาห์ที่ 2: รอยร้าวบนกำแพง

แล้วบางอย่างก็คลิก ผมเขียน Bash Alias ตัวแรก เข้าใจ `grep` พอจะใช้จริง ติดตั้ง `tmux` แล้วรู้สึกเหมือนแฮกเกอร์ในหนัง

## สัปดาห์ที่ 3: Flow State

พอเข้าสัปดาห์ที่ 3 ผมทำงานได้เร็วกว่าตอนใช้ Windows เสียอีก Terminal กลายเป็นส่วนขยายของความคิด `apt install` แทนที่การคลิก GUI อยู่ 15 นาที

## สิ่งที่อยากรู้ก่อน

| ปัญหา | วิธีแก้ |
|---------|----------|
| ไดร์เวอร์หาย | `ubuntu-drivers autoinstall` |
| ฟอนต์ไม่สวย | ติดตั้ง `fonts-noto` แล้วเปิด hinting |
| หาแอปไม่เจอ | เรียนรู้ `apt search` กับ `flatpak` |
| Terminal ขี้เหร่ | ติดตั้ง `kitty` + `zsh` + `powerlevel10k` |

## ฟันธง

เดือนแรกเจ็บปวด เดือนสองเริ่มคล่อง เดือนสามคุณจะถามตัวเองว่ารอมานานได้ยังไง

เลิก Dual Boot ซะ แล้วกระโดดเลย
