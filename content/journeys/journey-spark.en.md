## How It All Started

Late 2025 was when I finally decided to stop making excuses and start building something real. The Iterator Project wasn't born in a single flash of insight — it was the result of years of failed experiments, late-night coding sessions, and the growing realization that I needed a place to document it all.

### The Vision

I wanted to create more than just a portfolio. I wanted to build an open-source learning platform where every success *and* every failure is visible. A place where the code is shared, the process is transparent, and the lessons are free for anyone to learn from.

### The First Steps

It started with a simple question: *What if I treated my learning journey like open-source software?* Iterate, commit, push, repeat. Share the commit history — the bugs, the crashes, the breakthroughs.
